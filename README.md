# Kuyrukta Bekleyen Ruhlar Simülatörü

> **Resmi Uyarı:** Bu yazılım, Türk bürokrasisinin ruhani boyutunu simüle etmek amacıyla üretilmiştir. Kullanım sonucu oluşabilecek zaman kaybı, hayal kırıklığı ve varoluşsal bunalım kullanıcının sorumluluğundadır.

## Ne İşe Yarar?

Hiçbir şeye. Ama gerçekten çalışır.

Bu program, bir devlet dairesinde kuyruk beklemenin tüm şan ve şerefini dijital dünyaya taşır. Memurlar çay içer, fotokopi bozulur, öğle arası uzar, sistem 2019'dan beri güncellenir. Siz de bekler, beklersiniz.

## Kurulum

```bash
git clone https://github.com/Tentivory/kuyrukta-bekleyen-ruhlar-simulatoru.git
cd kuyrukta-bekleyen-ruhlar-simulatoru
python3 kuyruk_simulatoru.py
```

Python 3 yeterlidir. Bağımlılık yoktur. Tıpkı gerçek hayattaki gibi, hiçbir şey işe yaramaz ama yine de oradasınızdır.

## Özellikler

- Rastgele bürokratik engeller
- Gerçekçi bekleme süreleri (noktalarla gösterilir, çünkü ilerleme çubuğu lüks)
- %100 hayal kırıklığı garantisi
- Ctrl+C ile kuyruktan kaçma imkanı (nadir başarı)
- Gizli mesajlar (bazen)

## Lisans

Bu yazılım "Yarın Gel" lisansı altındadır. İstediğiniz gibi kullanabilirsiniz, ama yasal sorumluluk kabul edilmez. Memurlar da kabul etmez zaten.
